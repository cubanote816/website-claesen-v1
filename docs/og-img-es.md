Especificación para el cliente — Imagen    
  para redes sociales (OG Image)

  ---
  ¿Para qué sirve?
  Es la imagen que aparece automáticamente   
  cuando alguien comparte
  claesen-verlichting.be en LinkedIn,        
  Facebook, WhatsApp o X. Es la primera      
  impresión antes de que hagan clic.

  ---
  Lo que necesitamos de usted:

  Una foto de alta resolución de uno de sus  
  proyectos — preferiblemente una toma       
  nocturna de un estadio o instalación       
  industrial iluminada.

  ┌─────────────┬────────────────────────┐   
  │  Requisito  │        Detalle         │   
  ├─────────────┼────────────────────────┤   
  │ Formato     │ JPG o PNG              │   
  ├─────────────┼────────────────────────┤   
  │ Tamaño      │ 1200 × 630 píxeles     │   
  │ mínimo      │                        │   
  ├─────────────┼────────────────────────┤   
  │ Orientación │ Horizontal (landscape) │   
  ├─────────────┼────────────────────────┤   
  │             │ La foto más impactante │   
  │ Calidad     │  que tengan — estadio, │   
  │             │  mástil, instalación   │   
  │             │ industrial nocturna    │   
  ├─────────────┼────────────────────────┤   
  │             │ Sin texto encima —     │   
  │ Contenido   │ nosotros añadimos el   │   
  │             │ logo y tagline         │   
  └─────────────┴────────────────────────┘   

  Ejemplos válidos: foto de KVC Westerlo, RSC
  Anderlecht, C-mine Genk o cualquier        
  proyecto del que dispongan buena fotografía
  en alta resolución.

  ---
  Opcionalmente, si quieren imagen de marca  
  completa:

  Podemos crear la imagen final con logo +   
  foto + tagline. Para eso necesitamos       
  además:
  - Logo en formato SVG o PNG con fondo      
  transparente (versión blanca si existe)    
  - Confirmación del tagline: "Dé Belgische  
  specialist in terreinverlichting" o el que 
  prefieran

  ---
  Plazo sugerido: antes del smoke test en    
  servidor de producción, ya que bloquea el  
  og:image correcto en todas las páginas.
