## 📋 Instrucciones para descargar:

1. Visita cada sitio web oficial
2. Busca en "Media Kit", "Press Kit", o "Downloads"
3. Descarga el logo en formato PNG con fondo transparente
4. Renombra según el patrón: `club-nombre.png`
5. Tamaño recomendado: 200x200px o similar

## 🎨 Especificaciones:
- **Formato:** PNG con transparencia
- **Tamaño:** 200x200px (cuadrado)
- **Calidad:** Alta resolución
- **Naming:** kebab-case (ej: `club-brugge.png`)
